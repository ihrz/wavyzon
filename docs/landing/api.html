Wavyzon

API reference

The rustdoc of every crate in the workspace. Writing a plugin? Start with wavyzon_plugin; the plugin guide walks through it.

For plugin authors

  • wavyzon_pluginThe plugin API (sources, audio filters, event listeners, HTTP routes) and the shared model: tracks, failures, events.
  • wavyzon_plugin_exampleA complete plugin using every extension point: tone source, bitcrush filter, event counter, stats route.
  • wavyzon_plugin_apoEqualizer APO configurations as a playback filter: parser, biquads, GraphicEQ, partitioned convolution, reverb.

The node

  • wavyzonThe binary: configuration, REST and WebSocket server, sessions and resume, Lavalink v4 layer, plugin host, metrics.
  • wavyzon_playerThe two-deck player: crossfades, gapless, voice-overs, filters and glides, loudness, events, wire clock.
  • wavyzon_voiceDiscord voice: gateway v8, UDP/RTP, AEAD, DAVE end-to-end encryption, the 20 ms send loop.
  • wavyzon_sourcesDeezer, SoundCloud, HTTP, local files, Spotify and Apple Music metadata, the resolver and ISRC matching, caches.
  • wavyzon_analysisTempo, beats, key, phrases and loudness fingerprints, and the offline analysis queue.
  • wavyzon_audioPCM format, DSP blocks (biquad, sinc resampler, WSOLA stretcher, crossfade), decoding and Opus encoding.
  • wavyzon_testkitTest helpers: a fake Discord voice gateway, mock sources and audio assertions.
