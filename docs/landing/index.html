Your bot decides what to play; Wavyzon joins the voice channel, streams, mixes and filters the music, and tells your bot exactly when each sound reached Discord. It speaks Lavalink v4, so most bots switch by changing a host and a password.

Quick start Deploy on Pelican Examples Documentation Source

What you get

🎯 Wire clock

Positions measured when packets leave the socket: synced lyrics and progress bars line up with what people hear. How

🎚️ Two-deck mixing

Automatic crossfades into the next track, gapless albums, manual transitions and DJ voice-overs. Mixing

🔌 Lavalink v4

lavalink-client, Shoukaku, Moonlink, Wavelink, Lavalink4NET… connect unchanged. Compatibility

🎛️ Equalizer APO

Play through APO presets: AutoEQ, GraphicEQ, convolution reverbs, a one-line reverb. Filters

🎶 Sources

Deezer and SoundCloud playback, Spotify and Apple Music links matched by ISRC, HTTP files and radios. Sources

🔒 DAVE, pure Rust

Discord's end-to-end encryption without libdave: one static binary, no JVM. Architecture

🧩 Plugins

Add sources, audio filters, event listeners and HTTP routes in a few lines of Rust. Plugins

📈 Observable

Prometheus metrics, structured logs, every failure classified and counted. Metrics

Run it

Docker

# set WAVYZON_PASSWORD in .env
git clone https://gitlab.com/ihrz/wavyzon.git
cd wavyzon && cp .env.example .env
docker compose up -d

Your bot (lavalink-client)

nodes: [{
  id: "wavyzon",
  host: "localhost",
  port: 2333,
  authorization: process.env.WAVYZON_PASSWORD,
}]

On a game panel? Import the Pelican egg and the panel builds and runs it.
